# 2.3 Async Programming in LangChain: Concurrency Without Complexity

## 📌 Overview

Modern LLM applications must:

- Serve many users simultaneously
- Call external APIs
- Handle long-running operations
- Stream results in real time
- Scale efficiently

**Asynchronous programming (async)** enables concurrency without blocking threads.

LangChain provides first-class async support across:

- Chains
- Agents
- Tools
- Streaming
- Callbacks

---

# 🧠 Mental Model

### Sync (Blocking)

```
Task A → wait → Task B → wait → Task C
```

### Async (Concurrent I/O)

```
Start A
Start B
Start C
Wait for results as they complete
```

Async is ideal for:

- Network calls
- Database queries
- Streaming
- Web servers

---

# 🎯 Why Async Matters in LLM Apps

- ✅ FastAPI / async web frameworks
- ✅ Parallel tool calls
- ✅ Streaming tokens
- ✅ Efficient resource usage
- ✅ Lower memory footprint
- ✅ Higher throughput

---

# 🔑 Core Async Methods in LangChain

| Sync       | Async       |
| ---------- | ----------- |
| `invoke()` | `ainvoke()` |
| `stream()` | `astream()` |
| `batch()`  | `abatch()`  |

Async methods return **coroutines** → must be awaited.

---

# 1️⃣ Async Chains

All LCEL runnables support async if components do.

---

## 🔹 Basic Async Chain (`ainvoke`)

```python
import asyncio
from langchain.chat_models import ChatOpenAI
from langchain.prompts import ChatPromptTemplate

llm = ChatOpenAI(model="gpt-3.5-turbo")

prompt = ChatPromptTemplate.from_template(
    "Tell me a joke about {topic}"
)

chain = prompt | llm | (lambda msg: msg.content)

async def main():
    result = await chain.ainvoke({"topic": "programmers"})
    print(result)

asyncio.run(main())
```

---

## 🔹 Async Streaming (`astream`)

Perfect for web endpoints.

```python
async def stream_example():
    async for chunk in chain.astream({"topic": "robots"}):
        print(chunk, end="", flush=True)

asyncio.run(stream_example())
```

---

## 🔹 Async Batch Processing (`abatch`)

Runs multiple inputs concurrently.

```python
inputs = [
    {"topic": "cats"},
    {"topic": "dogs"},
    {"topic": "birds"}
]

async def batch_example():
    results = await chain.abatch(inputs)
    for res in results:
        print(res)

asyncio.run(batch_example())
```

---

### 🔹 Control Concurrency

```python
results = await chain.abatch(
    inputs,
    config={"max_concurrency": 5}
)
```

Prevents overwhelming APIs or rate limits.

# 2️⃣ Error Handling in Async

Use standard `try/except`.

For concurrent safety:

```python
async def safe_batch():
    tasks = [chain.ainvoke(inp) for inp in inputs]
    results = await asyncio.gather(
        *tasks,
        return_exceptions=True
    )

    for res in results:
        if isinstance(res, Exception):
            print(f"Error: {res}")
        else:
            print(res)
```

# 3️⃣ Async Agents

Agents are multi-step systems:

- LLM reasoning
- Tool calls
- Observations
- Final answer

Use:

```
executor.ainvoke()
executor.astream()
```

---

## 🔹 Basic Async Agent

```python
import asyncio
from langchain.agents import create_openai_tools_agent, AgentExecutor
from langchain.tools import tool
from langchain.chat_models import ChatOpenAI
from langchain.prompts import ChatPromptTemplate

@tool
async def fetch_weather(city: str) -> str:
    """Fetch weather (async mock)."""
    await asyncio.sleep(1)
    return f"The weather in {city} is sunny."

tools = [fetch_weather]

llm = ChatOpenAI(model="gpt-3.5-turbo", temperature=0)

prompt = ChatPromptTemplate.from_messages([
    ("system", "You are a helpful assistant."),
    ("user", "{input}"),
    ("placeholder", "{agent_scratchpad}")
])

agent = create_openai_tools_agent(llm, tools, prompt)
executor = AgentExecutor(agent=agent, tools=tools)

async def agent_example():
    result = await executor.ainvoke({
        "input": "What's the weather in Paris?"
    })
    print(result["output"])

asyncio.run(agent_example())
```

---

## 🔎 Important

- Async tools are awaited automatically.
- Sync tools are executed in a thread pool.
- Agent reasoning loop remains sequential.
- Parallel tool calls (if model supports them) run concurrently.

# 4️⃣ Async in FastAPI

### Basic Endpoint

```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Query(BaseModel):
    text: str

@app.post("/ask")
async def ask(query: Query):
    result = await executor.ainvoke(
        {"input": query.text}
    )
    return {"answer": result["output"]}
```

---

## 🔹 Streaming Endpoint

```python
from fastapi.responses import StreamingResponse

@app.post("/ask-stream")
async def ask_stream(query: Query):

    async def generate():
        async for chunk in executor.astream(
            {"input": query.text}
        ):
            if "output" in chunk:
                yield chunk["output"]

    return StreamingResponse(
        generate(),
        media_type="text/plain"
    )
```

# 5️⃣ Writing Async Tools (Real APIs)

Most real tools involve I/O (HTTP, DB).

Use async libraries like `aiohttp`.

---

## 🔹 Example: GitHub API Tool

```python
import aiohttp
from langchain.tools import tool

@tool
async def fetch_github_repo(repo_name: str) -> str:
    """Fetch GitHub repository information."""

    url = f"https://api.github.com/repos/{repo_name}"

    async with aiohttp.ClientSession() as session:
        async with session.get(url) as response:

            if response.status == 200:
                data = await response.json()
                return (
                    f"Repository: {data['name']}, "
                    f"Stars: {data['stargazers_count']}"
                )
            else:
                return f"Error: {response.status}"
```

---

## 🔹 Using Async Tools in Agent

```python
tools = [fetch_github_repo]

agent = create_openai_tools_agent(llm, tools, prompt)
executor = AgentExecutor(agent=agent, tools=tools)

result = await executor.ainvoke({
    "input": "Tell me about langchain-ai/langchain"
})
```

The executor:

- Detects async tool
- Awaits it automatically
- Handles concurrency internally

# 6️⃣ Mixing Sync and Async Tools

LangChain handles both:

| Tool Type  | Execution   |
| ---------- | ----------- |
| Async tool | awaited     |
| Sync tool  | thread pool |

For best performance:

- Convert I/O tools to async
- Avoid blocking calls

# 7️⃣ Advanced: Custom Async Runnables

You can create async-compatible components.

```python
from langchain.schema.runnable import Runnable
from typing import AsyncIterator
import asyncio

class AsyncCounter(Runnable[str, int]):

    async def ainvoke(self, input: str, config=None) -> int:
        await asyncio.sleep(1)
        return len(input)

    async def astream(self, input: str, config=None) -> AsyncIterator[int]:
        for i in range(len(input)):
            await asyncio.sleep(0.1)
            yield i + 1

counter = AsyncCounter()

chain = counter | (lambda x: f"Count: {x}")

async for chunk in chain.astream("hello"):
    print(chunk)
```

# 8️⃣ Concurrency Control Patterns

---

## 🔹 Timeout Protection

```python
result = await asyncio.wait_for(
    chain.ainvoke(...),
    timeout=10.0
)
```

---

## 🔹 Limit Concurrency with Semaphore

```python
semaphore = asyncio.Semaphore(5)

async def limited_invoke(inp):
    async with semaphore:
        return await chain.ainvoke(inp)
```

Prevents:

- API rate limits
- Resource exhaustion

---

## 🔹 Best Practice: Reuse Client Sessions

Instead of creating new `aiohttp.ClientSession()` per call:

- Create once
- Reuse for connection pooling
- Close on shutdown

---

# 9️⃣ Best Practices & Pitfalls

### ✅ Do

- Use `ainvoke`, `astream`, `abatch`
- Use async tools for I/O
- Use semaphores for rate limits
- Add timeouts
- Keep everything async in async apps

---

### ❌ Avoid

- Blocking sync calls in async code
- Using `asyncio.run()` inside FastAPI
- Ignoring rate limits
- Creating too many concurrent tasks
