# 2.5 Evaluation & Testing: Ensuring Quality and Reliability

## 📌 Overview

LLM applications are **not static systems**.

Every change:

- Prompt tweaks
- Model upgrades
- Retrieval adjustments
- Tool modifications

…can silently introduce regressions.

Evaluation ensures:

- ✅ Quality improvements are real
- ✅ No regressions are introduced
- ✅ Outputs remain factual & grounded
- ✅ CI/CD pipelines catch issues early

LangChain + **LangSmith** provide a full evaluation ecosystem.

---

# 🧠 Why Evaluation Matters in GenAI

### Traditional Software

Deterministic outputs → Easy unit tests

### LLM Systems

Probabilistic outputs → Need smarter evaluation

---

## 🎯 Core Goals

- Catch regressions
- Compare models/prompts
- Detect hallucinations
- Measure retrieval quality
- Automate testing in CI/CD
- Build trust in production

- Comparing versions

---

## 🔹 Setup LangSmith

1. Sign up at:
   [https://smith.langchain.com](https://smith.langchain.com)

2. Set environment variables:

```bash
export LANGCHAIN_TRACING_V2=true

```

Now every chain/agent execution is logged automatically.

---

## 🔹 Example: Tracing an Agent

```python
from langchain.chat_models import ChatOpenAI
from langchain.agents import create_openai_tools_agent, AgentExecutor
from langchain.prompts import ChatPromptTemplate
from langchain.tools import tool

llm = ChatOpenAI(model="gpt-3.5-turbo")

@tool
def add(a: int, b: int) -> int:
    return a + b

tools = [add]

prompt = ChatPromptTemplate.from_messages([
    ("system", "You are helpful."),
    ("user", "{input}"),
    ("placeholder", "{agent_scratchpad}")
])

agent = create_openai_tools_agent(llm, tools, prompt)
executor = AgentExecutor(agent=agent, tools=tools)

executor.invoke({"input": "What is 5 + 7?"})
```

View trace in LangSmith dashboard:

- Inputs
- Outputs
- Tool calls
- Latency
- Token usage

# 2️⃣ Evaluation Datasets

Evaluation requires **test data**.

LangSmith allows you to:

- Create datasets
- Add examples
- Run experiments against them

---

## 🔹 Create Dataset Programmatically

```python
from langsmith import Client

client = Client()

dataset = client.create_dataset(
    "Math QA",
    description="Simple math questions"
)

examples = [
    ("What is 2+2?", "4"),
    ("What is 10-3?", "7"),
    ("What is 5*6?", "30"),
]

for question, answer in examples:
    client.create_example(
        inputs={"input": question},
        outputs={"output": answer},
        dataset_id=dataset.id
    )
```

---

## 🔹 Dataset Structure

Each example contains:

- `inputs` → what goes into the chain
- `outputs` → expected result (ground truth)

# 3️⃣ Automated Evaluators

LangChain provides built-in evaluators.

They can:

- Compare predictions to references
- Use string similarity
- Use embeddings
- Use LLM-as-judge

---

## 🔹 Common Evaluator Types

| Evaluator            | Purpose                  |
| -------------------- | ------------------------ |
| `qa`                 | Q&A correctness          |
| `cot_qa`             | Chain-of-thought judging |
| `relevance`          | Retrieval relevance      |
| `hallucination`      | Groundedness check       |
| `embedding_distance` | Cosine similarity        |
| `string_distance`    | Levenshtein distance     |

---

## 🔹 Q&A Correctness Example

```python
from langchain.evaluation import load_evaluator
from langchain.chat_models import ChatOpenAI

evaluator = load_evaluator(
    "qa",
    llm=ChatOpenAI(model="gpt-4")
)

result = evaluator.evaluate_strings(
    prediction="The capital of France is Paris.",
    reference="Paris is the capital of France.",
    input="What is the capital of France?"
)

print(result)
```

---

## 🔹 Hallucination Detection (RAG)

```python
hallucination_evaluator = load_evaluator(
    "hallucination",
    llm=ChatOpenAI(model="gpt-4")
)

result = hallucination_evaluator.evaluate_strings(
    prediction="LangChain was created in 2022.",
    input="When was LangChain created?",
    contexts=[
        "LangChain was introduced in October 2022 by Harrison Chase."
    ]
)

print(result)
```

Score near:

- 1 → grounded
- 0 → hallucinated

---

## 🔹 Retrieval Relevance

```python
relevance_evaluator = load_evaluator(
```

# 4️⃣ Running Dataset Evaluations

You can evaluate entire datasets using LangSmith.

---

## 🔹 Using RunEvalConfig

```python
from langchain.smith import RunEvalConfig, run_on_dataset

eval_config = RunEvalConfig(
    evaluators=[
        "qa",
        "cot_qa",
        "relevance"
    ],
    custom_evaluators=[]
)

run_on_dataset(
    client=client,
    dataset_name="Math QA",
    llm_or_chain_factory=my_chain,
    evaluation=eval_config
)
```

# 5️⃣ Custom Evaluators

Built-in evaluators may not cover:

- Style constraints
- Business rules
- Compliance requirements
- Domain-specific correctness

You can create your own.

---

## 🔹 Rule-Based Custom Evaluator

```python
from langchain.evaluation import StringEvaluator
from typing import Optional, Dict, Any

class MyLengthChecker(StringEvaluator):

    def __init__(self, max_length=100):
        self.max_length = max_length

    @property
    def evaluation_name(self) -> str:
        return "length_checker"

    def _evaluate_strings(
        self,
        prediction: str,
        input: Optional[str] = None,
        reference: Optional[str] = None,
        **kwargs: Any
    ) -> Dict[str, Any]:

        score = 1.0 if len(prediction) <= self.max_length else 0.0

        return {
            "score": score,
            "value": len(prediction)
        }
```

---

## 🔹 LLM-as-Judge Custom Metric

Example: Evaluate friendliness.

```python
from langchain.evaluation import load_evaluator
from langchain.prompts import PromptTemplate
from langchain.chat_models import ChatOpenAI

friendly_prompt = PromptTemplate.from_template("""
Grade the response for friendliness (1-5).
Response: {prediction}
Score:
""")

llm = ChatOpenAI(model="gpt-3.5-turbo")

friendly_evaluator = load_evaluator(
    "criteria",
    llm=llm,
    criteria="friendliness",
    prompt=friendly_prompt
)

result = friendly_evaluator.evaluate_strings(
    prediction="I don't know.",
    input="How are you?"
)

print(result)
```

# 6️⃣ Complete Evaluation Workflow (RAG Example)

---

## 🔹 Step 1: Setup

```python
import os
from langsmith import Client

os.environ["LANGCHAIN_TRACING_V2"] = "true"
os.environ["LANGCHAIN_API_KEY"] = "your-api-key"

client = Client()
```

---

## 🔹 Step 2: Build RAG Chain

```python
from langchain.chat_models import ChatOpenAI
from langchain.vectorstores import Chroma
from langchain.embeddings import OpenAIEmbeddings
from langchain.chains import create_retrieval_chain
from langchain.chains.combine_documents import create_stuff_documents_chain
from langchain.prompts import ChatPromptTemplate

embeddings = OpenAIEmbeddings()
vectorstore = Chroma(
    embedding_function=embeddings,
    persist_directory="./policy_db"
)

retriever = vectorstore.as_retriever()

prompt = ChatPromptTemplate.from_messages([
    ("system", "Answer based on context: {context}"),
    ("user", "{input}")
])

llm = ChatOpenAI(model="gpt-3.5-turbo", temperature=0)

combine_docs_chain = create_stuff_documents_chain(llm, prompt)

rag_chain = create_retrieval_chain(
    retriever,
    combine_docs_chain
)
```

---

## 🔹 Step 3: Define Evaluators

```python
eval_config = RunEvalConfig(
    evaluators=[
        "qa",
        "cot_qa",
        "relevance",
        "hallucination"
    ],
    custom_evaluators=[
        MyLengthChecker(max_length=200)
    ]
)
```

---

## 🔹 Step 4: Run Experiment

```python
run_on_dataset(
    client=client,
    dataset_name="Policy QA",
    llm_or_chain_factory=lambda: rag_chain,
    evaluation=eval_config,
    project_name="policy-qa-eval-v1",
    verbose=True
)
```

Results → Visible in LangSmith dashboard.
