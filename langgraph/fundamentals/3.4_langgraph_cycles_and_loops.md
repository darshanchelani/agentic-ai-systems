# 3.4 Cycles & Loops: Creating Iterative Workflows

Cycles allow a graph to revisit nodes, enabling workflows that:

- Refine answers iteratively
- Call tools multiple times
- Engage in multi-turn reasoning

**Important:** Always design termination conditions to prevent infinite loops.

---

# Building Cycles – Edges That Go Back

Cycles are created by adding edges to nodes that have already executed. Use `add_edge` or `add_conditional_edges`.

### Example: Retry Loop in QA Graph

```python
from typing import TypedDict, List, Annotated
import operator
from langgraph.graph import StateGraph, END

class State(TypedDict):
    query: str
    retrieved_docs: Annotated[List[str], operator.add]
    answer: str
    attempts: int

def retrieve(state: State) -> dict:
    attempt = state.get("attempts", 0) + 1
    docs = [f"Result for '{state['query']}' (attempt {attempt})"]
    return {"retrieved_docs": docs, "attempts": attempt}

def generate(state: State) -> dict:
    return {"answer": f"Based on: {state['retrieved_docs'][-1]}"}

def check(state: State) -> dict:
    return {"need_more": len(state["answer"]) < 20 and state["attempts"] < 3}

def route(state: State) -> str:
    return "retrieve" if state.get("need_more") else "end"

builder = StateGraph(State)
builder.add_node("retrieve", retrieve)
builder.add_node("generate", generate)
builder.add_node("check", check)

builder.set_entry_point("retrieve")
builder.add_edge("retrieve", "generate")
builder.add_edge("generate", "check")
builder.add_conditional_edges("check", route, {"retrieve": "retrieve", "end": END})

app = builder.compile()
```

**Use Cases for Cycles**

- Agent loops (tool selection)
- Iterative answer refinement
- Retry logic
- Multi-turn conversations

# Termination – Using `END`

The special node `END` stops a path.

### Explicit edge to END

```python
builder.add_edge("final_node", END)
```

### Conditional edge to END

```python
def route(state: State) -> str:
    return "end" if state.get("finished") else "next_node"

builder.add_conditional_edges("check_node", route, {"end": END, "next_node": "process"})
```

**Notes**

- Every path must eventually reach `END`.
- Multiple paths can point to `END`.
- Dead ends (nodes without outgoing edges) cause validation errors.

---

# Preventing Infinite Loops

### 1. Recursion Limit

Limits total node invocations to prevent runaway loops.

```python
result = app.invoke(initial_state, {"recursion_limit": 50})
```

Exceeding the limit raises `GraphRecursionError`.

### 2. State-Based Counters

Maintain counters in the state to terminate cycles.

```python
def retrieve(state: State) -> dict:
    attempts = state.get("attempts", 0) + 1
    if attempts > 5:
        return {"attempts": attempts, "force_end": True}
    return {"retrieved_docs": [...], "attempts": attempts}

def route(state: State) -> str:
    return "end" if state.get("force_end") else "retrieve"
```

### 3. Timeouts

Use Python `asyncio` or threads to enforce timeouts.

```python
import asyncio

async def run_with_timeout(app, initial_state, timeout=10):
    try:
        result = await asyncio.wait_for(app.ainvoke(initial_state), timeout)
        return result
    except asyncio.TimeoutError:
        print("Graph execution timed out")
        return None
```

### 4. Static Cycle Detection

- Compilation detects dead ends (nodes without path to `END`).
- Runtime exit conditions must still be defined.

# Complete Example: Agent Tool-Calling Loop

```python
from typing import TypedDict, List, Annotated
import operator
from langgraph.graph import StateGraph, END

class AgentState(TypedDict):
    messages: Annotated[List[str], operator.add]
    tool_calls: int
    finished: bool

def search_tool(query: str) -> str:
    return f"Result for '{query}'"

def call_llm(state: AgentState) -> dict:
    if state.get("tool_calls", 0) < 2:
        return {"messages": ["LLM: I need to search."], "tool_calls": state.get("tool_calls", 0) + 1}
    else:
        return {"messages": ["LLM: Here's the final answer."], "finished": True}

def execute_tool(state: AgentState) -> dict:
    return {"messages": [f"Tool: {search_tool('weather')}"]}

def route_agent(state: AgentState) -> str:
    return "end" if state.get("finished") else "call_llm"

builder = StateGraph(AgentState)
builder.add_node("call_llm", call_llm)
builder.add_node("execute_tool", execute_tool)

builder.set_entry_point("call_llm")
builder.add_edge("call_llm", "execute_tool")
builder.add_conditional_edges("execute_tool", route_agent, {"call_llm": "call_llm", "end": END})

app = builder.compile()

initial = {"messages": [], "tool_calls": 0, "finished": False}
try:
    result = app.invoke(initial, {"recursion_limit": 10})
    print(result["messages"])
except Exception as e:
    print(f"Stopped: {e}")
```

# Summary

| Concept                       | How to Implement                                      | Use Case                                 |
| ----------------------------- | ----------------------------------------------------- | ---------------------------------------- |
| **Building cycles**           | `add_edge` / `add_conditional_edges` to previous node | Agent loops, retry, iterative refinement |
| **Termination**               | Edge to `END` node                                    | End the graph safely                     |
| **Preventing infinite loops** | Recursion limit, state counters, timeouts             | Production safety and cost control       |

**Key Takeaway:**
Cycles enable iterative, self-improving workflows. Always combine them with robust termination conditions and runtime safeguards.
