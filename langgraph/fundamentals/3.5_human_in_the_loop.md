````markdown
# 3.5 Human‑in‑the‑Loop: Interrupts, Checkpointing, and Resuming

LangGraph allows pausing execution to let humans provide input, then resuming workflows seamlessly. This is achieved through:

- **Interrupts** – Pause at a node
- **Checkpointing** – Save graph state
- **Resuming** – Continue from pause with updates

---

# Why Human‑in‑the‑Loop?

- **Safety**: Validate actions before executing.
- **Quality**: Confirm or correct uncertain outputs.
- **Interactive workflows**: Clarify ambiguous user queries.
- **Compliance**: Human oversight for regulated operations.

---

# 1. Interrupts – Pause Execution with `NodeInterrupt`

An interrupt stops the graph and waits for human input.

```python
from langgraph.errors import NodeInterrupt

def human_approval_node(state: dict) -> dict:
    action = state.get("proposed_action")
    print(f"Proposed action: {action}")
    raise NodeInterrupt(f"Approve action: {action}")
```
````

**Notes:**

- Execution stops immediately.
- Node does not complete until resumed.
- Requires checkpointing to resume later.

---

# 2. Checkpointing – Persist State

Checkpointing saves the current state and pending execution stack.

### Using `MemorySaver`:

```python
from langgraph.checkpoint import MemorySaver

checkpointer = MemorySaver()
app = builder.compile(checkpointer=checkpointer)
```

**Saved data:**

- Current state
- Execution stack
- Metadata and configuration

**Thread ID** links multiple interactions in the same session:

```python
thread_config = {"configurable": {"thread_id": "user-123"}}
app.invoke(initial_state, thread_config)
```

---

# 3. Resuming – Continue Graph Execution

After an interrupt, resume by providing the same thread ID and optional updates:

```python
user_input = {"approved": True, "comment": "Looks good"}
final_state = app.invoke(None, thread_config, updates=user_input)
```

**Key points:**

- Graph resumes at the interrupted node.
- Updates are merged into state before re-execution.
- Node code must handle both initial and resumed execution.

### Example Node Handling Interrupt and Resume

```python
def approval_node(state: dict) -> dict:
    if "human_approved" in state:
        return {"status": "approved" if state["human_approved"] else "rejected", "steps": ["approved" if state["human_approved"] else "rejected"]}
    else:
        print(f"Proposed: {state.get('action')}")
        raise NodeInterrupt("Need human approval")
```

# Complete Example: Human Approval for Transaction

```python
from typing import TypedDict, List, Annotated
import operator
from langgraph.graph import StateGraph, END
from langgraph.checkpoint import MemorySaver
from langgraph.errors import NodeInterrupt

class TransactionState(TypedDict):
    request: dict
    summary: str
    approved: bool
    executed: bool
    steps: Annotated[List[str], operator.add]

# Nodes
def summarize_transaction(state: TransactionState) -> dict:
    request = state["request"]
    return {"summary": f"Transaction: {request['amount']} USD to {request['payee']}", "steps": ["summarized"]}

def human_approval(state: TransactionState) -> dict:
    if "approved" not in state:
        print(f"APPROVAL REQUIRED: {state['summary']}")
        raise NodeInterrupt("Waiting for human approval")
    return {"steps": ["human_decision_recorded"]}

def execute_payment(state: TransactionState) -> dict:
    if state.get("approved"):
        print(f"Executing payment: {state['summary']}")
        return {"executed": True, "steps": ["executed"]}
    return {"executed": False, "steps": ["rejected"]}

def route_after_approval(state: TransactionState) -> str:
    return "execute" if state.get("approved") else END

# Build graph
builder = StateGraph(TransactionState)
builder.add_node("summarize", summarize_transaction)
builder.add_node("approval", human_approval)
builder.add_node("execute", execute_payment)

builder.set_entry_point("summarize")
builder.add_edge("summarize", "approval")
builder.add_conditional_edges("approval", route_after_approval, {"execute": "execute", END: END})
builder.add_edge("execute", END)

# Compile with checkpointing
checkpointer = MemorySaver()
app = builder.compile(checkpointer=checkpointer)

# Run
thread_config = {"configurable": {"thread_id": "tx-123"}}
initial_state = {"request": {"amount": 100, "payee": "Alice", "currency": "USD"}, "steps": []}

try:
    result = app.invoke(initial_state, thread_config)
except NodeInterrupt as e:
    print(f"Interrupted: {e}")

# Resume with human input
human_decision = {"approved": True}
final_state = app.invoke(None, thread_config, updates=human_decision)
print("Final state:", final_state)
```

# Where to Use Human‑in‑the‑Loop

| Scenario                    | Interrupt Point    | Human Input                   |
| --------------------------- | ------------------ | ----------------------------- |
| Action approval (send, pay) | Before action node | Approve/reject                |
| Clarifying ambiguous query  | After retrieval    | Provide extra context         |
| Correcting model output     | After generation   | Edit answer before continuing |
| Multi-turn chat handoff     | Handoff node       | Human takes over              |
| Data collection             | Form-filling node  | User fills required fields    |

---

# Summary

| Feature       | Purpose                                    |
| ------------- | ------------------------------------------ |
| Interrupts    | Pause execution at a node                  |
| Checkpointing | Persist state and execution stack          |
| Resuming      | Continue graph from interrupt with updates |

**Key Takeaway:**
Human-in-the-loop allows AI workflows to be collaborative, safe, and compliant. Always use checkpointing to resume exactly where the graph paused.
