# 3.3 Graph Compilation & Execution: Bringing Your Graph to Life

After defining nodes, edges, and state schema, you must **compile** the graph into an executable object. This prepares the graph for efficient execution and allows you to run it synchronously or asynchronously.

---

# 1. Compile – `graph.compile()`

Compilation transforms a graph definition into a **runnable `CompiledGraph`**.

### What Compilation Does

- **Validation**: Checks for orphaned/unreachable nodes, missing entry point, or cycles that could loop infinitely.
- **Optimization**: Prepares internal data structures for fast execution.
- **Checkpointing setup**: Attaches persistence if configured.
- **Interrupt handling**: Configures breakpoints if needed.

### Example

```python
from langgraph.graph import StateGraph

builder = StateGraph(GraphState)
# ... add nodes and edges ...
builder.set_entry_point("start_node")
app = builder.compile()  # Returns CompiledGraph
```

### Notes

- `app` supports `invoke`, `stream`, `ainvoke`, `astream`.
- Compile once per graph; reusable and thread-safe.
- Usually done at module-level setup.

---

# 2. Invoke – `app.invoke(initial_state)`

Runs the graph **synchronously to completion**, returning the final state.

### Use Cases

- Batch processing
- Scripts and background jobs
- When intermediate states are not needed

### Example

```python
initial_state = {"query": "What is LangGraph?", "attempts": 0}
final_state = app.invoke(initial_state)
print(final_state["answer"])
```

### Under the Hood

- Starts at the entry point.
- Executes nodes in edge-defined order.
- Merges node updates (using reducers if defined).
- Conditional edges determine next nodes.
- Returns final state when `END` is reached.

---

# 3. Stream – `app.stream(initial_state)`

Returns a **generator** that yields intermediate state updates as the graph executes.

### Use Cases

- Debugging
- Showing progress (e.g., "retrieving...", "generating...")
- Interactive UIs

### Example

```python
for step in app.stream(initial_state):
    print(step)  # State after each node or super-step
```

### Streaming with Agents

```python
for step in app.stream({"input": "What's 5+3?"}):
    if 'agent' in step:
        print("Agent thinking...")
    if 'tools' in step:
        print(f"Tool result: {step['tools']}")
```

---

# 4. Async – `ainvoke` and `astream`

For graphs with **async nodes** or async environments (FastAPI, asyncio):

### `ainvoke` Example

```python
async def main():
    final_state = await app.ainvoke({"query": "LangGraph", "attempts": 0})
    print(final_state["answer"])
```

### `astream` Example

```python
async def main():
    async for step in app.astream({"query": "LangGraph", "attempts": 0}):
        print(step)
```

### Notes

- Must use async methods if graph has async nodes.
- Async execution uses `asyncio` for concurrency.
- Can run sync nodes in a thread pool if needed.

---

# Complete Example: Compilation & Execution Modes

```python
import asyncio
from typing import TypedDict, List, Annotated
import operator
from langgraph.graph import StateGraph, END

class GraphState(TypedDict):
    query: str
    retrieved_docs: Annotated[List[str], operator.add]
    answer: str
    attempts: int
    steps: Annotated[List[str], operator.add]

# Nodes
def retrieve(state: GraphState) -> dict:
    attempts = state.get("attempts", 0) + 1
    docs = [f"Doc about {state['query']} (attempt {attempts})"]
    return {"retrieved_docs": docs, "steps": ["retrieve"], "attempts": attempts}

def generate(state: GraphState) -> dict:
    docs = state.get("retrieved_docs", [])
    return {"answer": f"Based on: {docs[-1]}", "steps": ["generate"]}

def check(state: GraphState) -> dict:
    answer = state.get("answer", "")
    if len(answer) < 20 and state.get("attempts", 0) < 2:
        return {"steps": ["check: need more docs"]}
    else:
        return {"steps": ["check: answer ok"]}

def format_answer(state: GraphState) -> dict:
    return {"answer": f"Final: {state['answer']}", "steps": ["format"]}

def route_after_check(state: GraphState) -> str:
    return "retrieve" if "check: need more docs" in state["steps"] else "format"

# Build & compile
builder = StateGraph(GraphState)
builder.add_node("retrieve", retrieve)
builder.add_node("generate", generate)
builder.add_node("check", check)
builder.add_node("format", format_answer)
builder.set_entry_point("retrieve")
builder.add_edge("retrieve", "generate")
builder.add_edge("generate", "check")
builder.add_conditional_edges("check", route_after_check)
builder.add_edge("format", END)

app = builder.compile()

# 1. Sync invoke
result = app.invoke({"query": "LangGraph", "attempts": 0})
print("Sync invoke:", result["answer"])

# 2. Sync stream
for step in app.stream({"query": "LangGraph", "attempts": 0}):
    print("Stream step:", step)

# 3 & 4. Async
async def run_async():
    final_state = await app.ainvoke({"query": "LangGraph", "attempts": 0})
    print("Async invoke:", final_state["answer"])

    async for step in app.astream({"query": "LangGraph", "attempts": 0}):
        print("Async stream step:", step)

asyncio.run(run_async())
```

---

# Summary of Execution Methods

| Method    | Returns                 | When to Use                               |
| --------- | ----------------------- | ----------------------------------------- |
| `invoke`  | Final state (dict)      | Sync, final output only                   |
| `stream`  | Generator of steps      | Intermediate updates, progress, debugging |
| `ainvoke` | Coroutine → final state | Async graph or async environment          |
| `astream` | Async generator         | Async streaming, UIs, multi-step agents   |

- All accept the same initial state.
- Compiled graph is reusable and thread-safe.
- Supports cycles, concurrency, conditional routing, checkpoints, and interrupts.

---

# Under the Hood

1. Copy of initial state is made.
2. Starts at entry node.
3. For each node:
   - Execute node function with current state.
   - Merge updates (reducers applied if any).
   - Evaluate outgoing edges:
     - Normal → direct next node
     - Conditional → routing function decides next node(s)

   - Parallel branches run concurrently.

4. Path ends when no outgoing edges or `END` is reached.
5. Graph finishes when all paths terminate; final state is merged result.

LangGraph executor handles cycles, concurrency, and complex routing efficiently.
